# 🛒 shopping-listapp

HTML / CSS / JavaScript만으로 만든 간단한 쇼핑 리스트 앱입니다.
별도의 서버나 빌드 과정 없이 브라우저에서 바로 실행되며, 목록은 브라우저의 `localStorage`에 저장됩니다.

## ✨ 주요 기능

| 기능 | 설명 |
| --- | --- |
| **아이템 추가** | 입력창에 물건 이름을 쓰고 `추가` 버튼 또는 Enter로 등록 (최대 100자, 앞뒤 공백 제거, 빈 값은 무시) |
| **구매 완료 체크** | 체크박스 또는 아이템 이름을 클릭해 완료 표시/해제 |
| **개별 삭제** | 각 아이템 오른쪽의 `×` 버튼으로 삭제 |
| **체크된 항목 일괄 삭제** | 하단 `체크된 항목 삭제` 버튼으로 완료한 아이템만 한 번에 정리 (완료 항목이 없으면 비활성화) |
| **진행 현황 요약** | 상단에 `전체 N개 · 완료 M개` 형태로 표시 |
| **빈 목록 안내** | 아이템이 없을 때 "아직 추가된 아이템이 없습니다." 메시지 표시 |
| **자동 저장** | 추가·체크·삭제할 때마다 `localStorage`에 저장되어 새로고침하거나 브라우저를 다시 열어도 유지 |

## 🚀 실행 방법

1. 저장소를 내려받습니다.
   ```bash
   git clone https://github.com/winsHyun/shopping-listapp.git
   ```
2. `index.html`을 브라우저로 엽니다.

설치할 패키지나 빌드 과정은 없습니다.

## 📁 프로젝트 구조

```
shopping-listapp/
├── index.html   # 화면 구조 (입력 폼, 목록, 요약, 하단 버튼)
├── style.css    # 스타일
├── app.js       # 아이템 추가/체크/삭제, 렌더링, localStorage 저장 로직
└── README.md
```

## 🛠 구현 포인트

- **데이터 저장**: 아이템 목록을 `shopping-list-items` 키로 `localStorage`에 JSON 형태로 저장합니다.
  저장소를 쓸 수 없거나 데이터가 손상된 경우에도 빈 목록으로 시작해 앱이 멈추지 않습니다.
- **아이템 데이터 형태**
  ```js
  { id: "lq3x9a1b2c", name: "우유", checked: false }
  ```
- **이벤트 위임**: 체크와 삭제 이벤트를 각 아이템이 아닌 목록(`<ul>`) 하나에서 처리합니다.
- **안전한 렌더링**: 아이템 이름을 `textContent`로 넣어 입력값이 HTML로 해석되지 않습니다.
- **접근성**: 체크박스와 이름을 `<label>`로 연결하고, 삭제 버튼에 `aria-label`을 지정했습니다.

## ⚠️ 참고

- 데이터는 사용 중인 브라우저에만 저장되므로 다른 기기나 브라우저와는 공유되지 않습니다.
- 브라우저의 사이트 데이터를 지우면 목록도 함께 삭제됩니다.
